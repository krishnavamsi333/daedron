# Daedron

Robotics Motor Controller

## Overview

Daedron is a motor controller board designed for robotics and
electromechanical actuator applications.

The project focuses on motor power control, feedback sensing,
real-time control, and reliable communication between distributed
robotic systems.

## Intended Applications

- Mobile robots
- Robotic actuators
- Motorized mechanisms
- Distributed motion-control systems
- Embedded robotics platforms

## Planned Features

- STM32 microcontroller
- DC/BLDC motor control
- MOSFET power stage
- Gate-driver interface
- Motor current sensing
- Voltage and temperature monitoring
- Encoder interface
- CAN communication
- Hardware fault protection
- Status and diagnostic indicators

## Hardware

The PCB is designed using KiCad.
